# 8.7 材质提示词组装规则

1. 任务：局部编辑使用当前效果图与实际遮罩，选区外不变；效果图生成使用对应生成任务模板。
2. 表面：从材质 surface.md 读取漆膜、缎面反射或闪粉等特征。
3. 颜色：亚金、亚银自动使用目录固有色（金 #c8a86b、银 #c7cbd0）；烤漆、透明漆、闪粉保留原底色。取样色仅用于定位选区。无需用户选择颜色策略，旧草稿中的 preserve 不覆盖金银规则。
4. 避免项：从材质 avoid.md 读取，不将材质样片摄影条件混入实际编辑。
5. 局部保持项：继承原视角与照明，保持图案、文字、宏观几何及区域边界；金银替换允许选区底色改变。
6. 强度：局部列表固定 150%，作为表现要求传入，不解释为 API 数值强度参数。
7. 后处理：金银以材质固有色为色度依据，保留生成的反射、纹理与亮度；其他材质以原色为依据并校正共同曝光偏移。最终按原遮罩合成，遮罩外保持原图。

8.7 多区域编辑每层一次模型生成，不再进行第二次颜色生成。旧单材质分支仍有颜色修正，但金银须携带材质本色例外。

实现：后端 material_policy.py 为 8.7 配置入口；前端 local regions 读写与执行配置采用同样映射。共享底层提示词函数继续接受显式颜色策略，以保持其他调用方兼容。

## 金银局部编辑定位修正（2026-09-17）

金银分层编辑先在模型输入副本的实际选区内设置目标金银底色，保留受限的原光照变化；同时将同一遮罩编码为不透明黑白定位图（白色编辑、黑色保护）。模型负责表面反射，最终仍用未改动的原图与原遮罩确定性合成。此路径不再使用原生 alpha mask 参数，避免本次实测出现的选区黑洞。其他材质仍使用原 alpha mask 路径。若金银候选图过半选区为近黑，停止合成并报告失败，不输出黑块成品。
