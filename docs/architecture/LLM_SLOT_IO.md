# LLM 优化节点 Slot 输入输出

输入只读取原生图的持久连线。旧 inputIds、source、uploaded 数据保留以便人工迁移，但不再作为隐式输入。保留原槽位索引，末尾增加其他输入槽位，用于报告不可解析类型。

支持公开 Canvas 输入快照中的文字、图片、素材组，业务表格快照，以及原生 PrimitiveString、PrimitiveStringMultiline、LoadImage 和可读取的字符串输出。含视频、缺失资源或不明确的表格列时拒绝生成。纯图片自动选择图片反推；纯文字自动选择提示词润色。混合输入保留用户所选模式。

图文混合素材组通过 `inputMode:image-instructions` 声明用途：组内文字按顺序组成处理要求，图片进入参考图片区并自动切换到图片反推。要求跟随输入连线，原组可编辑，LLM 中为只读映射；断开该输入后恢复节点原有手动要求。同组多张图片按序串行处理，共用组内要求，不修改原始素材。

从 LLM 输出 Slot 拖到空白处，Canvas 根据适配器 `defaultOutputNode` 声明创建“优化结果”文本节点及真实 STRING 连线。文本节点复用基础输入文本面板；有连线时只读跟随已应用结果，撤销或上游内容改变后清空并等待；断线后恢复本节点的手动文本。

生成结果是建议，应用后才发布。结果 STRING 槽输出按原序用空行连接的已应用文字。LLM 下游通过公开 inputSnapshot 读取；原生队列通过 ApprovedLLMResult 返回已应用文本，不调用模型。撤销恢复前一次应用；上游、模式、处理要求、模型改变时旧输出不可用。未应用或失效结果不能提交给已连接下游。

复用共享 Slot 交互、按钮、字段、面板可用性与 adapter.tasks 胶囊。任务状态仅保留于运行时，不写入工作流。模型服务继续使用原有并发 1 和 GPU admission gate。
