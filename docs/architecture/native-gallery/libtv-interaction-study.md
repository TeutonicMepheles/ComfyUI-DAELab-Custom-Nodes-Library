# LibTV 交互观察与创作画布适配

2026-09-28，通过用户提供的 LibTV 画布观察实际页面、双击菜单、节点选中及拖线松手菜单，并读取可见 DOM 的计算样式。没有提取服务端实现或引入站点脚本、品牌资源。

## 观察值

- 画布背景 #141414、点阵 #474747；菜单背景 #262626、边框 #363636。
- 菜单最小宽度 220px、内边距 6px、圆角 16px；菜单项高 36px、横向 padding 8px、圆角 10px；文字 16px。
- 连线默认 #86909c、悬停 #c0c8d0、选中 #e0e4e8。节点选择边框 #a8a8a8。
- 标题与内容具有层次；接口在两侧中线，选中状态强化；拖线松手面板按兼容性禁用条目。
- 节点选中后显示编辑操作区域；底部独立工具栏属于该产品导航组织方式。

## 本轮实施

1. 将共享主题调整为中性深灰，保留 M3 的语义颜色、无障碍焦点、状态与既有本地普惠体。
2. 四项菜单使用 224px 宽、8px 内边距、40px 行高、16px 外圆角；比参考稍宽松，兼顾中文和键盘焦点。
3. 连线默认灰、悬停和选中强化；未连接接口弱化，选中/悬停/焦点强化，仍始终可见、可连接。
4. 四种节点复用本地 Remix 类别图标和中文类型胶囊，完整类型 ID 留在提示中。旧节点类型仍保留。
5. 菜单补充上下方向键、Home/End 导航，跳过禁用项。保留 Enter、Escape、Tab 原生行为。

不引入底部多按钮工具栏；不改变节点业务、不复制品牌图标、不迁移上游面板。复用 creative_theme、creative_canvas_catalog、现有 socket/menu 事件与共享控件，不新增平行控件体系。

验收：真实画布菜单、两个节点、连线、节点重命名、选择状态、窄屏和缩放、模式切换；检查溢出、裁切、字体、按钮语义。状态：首轮实现完成，运行时视觉验收待完成。
