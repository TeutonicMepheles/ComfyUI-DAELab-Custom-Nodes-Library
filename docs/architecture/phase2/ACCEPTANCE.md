# 验收操作与证据约定

> 范围以[本轮改造范围](../SCOPE.md)为准：仅现有创作画布及相关节点；展厅、徽章 App Mode 不调整。

以下用例全部为待执行。第二阶段验收是检查用例和契约完整性；第三阶段实现独立陈列后执行，第四阶段补真实宿主执行。只读 ComfyTV 原生界面和未迁移组件不在共享更新覆盖承诺内。

## U01 共享修改传播（所有 C01—C06）

准备：同组件 A/B 两实例，素材、标题和参数不同；陈列记录唯一源码路径与构建版本。第四阶段增加两个真实节点，并保存旧工作流。

操作：只改组件唯一源码的一项样式和一种共享行为；不改消费方。样式可临时将圆角增加 2px；行为选择：C01 激活前统一校验、C02 提交规范化、C03 默认焦点目标、C04 错误重试反馈、C05 恢复按钮忙碌保护、C06 键盘移动步长。修改必须不破坏既定契约；临时差异只用于证明传播。

预期：重新构建并刷新后全部目标实例具有同样改变；读取的资源版本一致。源码检查证明引用同一实现，而不是肉眼相似。修改 A 的数据后 B 不变。恢复临时改动后再次核对。

证据：修改 diff、消费引用路径、构建版本、前后截图、行为日志、A/B 数据断言。第三阶段只证明陈列；第四阶段覆盖陈列+两个真实节点。

## U02 按钮状态与焦点（C01）

鼠标、Enter、Space 分别激活，单次仅一次事件；busy/disabled 各重复点击 3 次，事件为零；iconOnly 可读名称正确；Tab 焦点清晰。320px 容器不挤掉标签，busy 不跳尺寸。检查标准按钮和图标按钮共用实现。

## U03 输入与持久化（C02）

数字非法输入、0、空值、中文组合输入、select 已存值不再可用分别测试；无效值不提交，0 不被默认值替换。编辑草稿时注入外部 value 变化，要求明确冲突处理。保存/重开旧工作流验证显式值保留；未设置字段采用新默认。A 编辑不改变 B；一个逻辑提交只有一个撤销步骤。表格键盘导航另做集成回归。

## U04 浮层/卡片生命周期（C03/C06）

打开参数浮层，再打开媒体模态；Escape 只关闭最内层。guarded 草稿外部点击不能丢失。关闭返回触发器；删除触发节点后安全返回画布。卡片按钮/文本/视频交互不启动拖动，标题超过阈值才拖动。测试 pointercancel、键盘移动取消、缩放下拖动位置。反复切模式与挂载/卸载 10 次：无多余 DOM、订阅、Observer 或轮询；非 Active 恢复数据不变。

## U05 媒体来源与暂停（C04）

使用两份不同本地样例、无效 URL、延迟加载；错误实例不显示另一素材。视频播放后关闭/隐藏/卸载，确认暂停。更换素材时旧异步结果不能覆盖新素材。cover 缩略图展开后 contain；输入/输出角色明确，取色使用真实来源。整个用例不需生成或外部付费调用。

## U06 任务显示与重复操作（C05）

模拟 idle、validating、queued、running、succeeded、failed、stopping、stopped、unknown；无进度时不显示假百分比。能力为 false 无动作，恢复点击不转成新生成；停止提示明确只涉及未提交项。A 的进度不改变 B。后端恢复幂等性留在第五、六阶段真实链路验收，本用例仅验证 UI 契约。

## 独立陈列验收附加项

停止 ComfyUI 后仍能启动，样例和服务均本地模拟；断网不影响已安装后的陈列资源加载。每组件可切状态、变体、紧凑密度和窄容器；实际色彩对比度检查符合 DESIGN 项目目标；禁止引用 app、graph、PromptServer 或生产凭据。组件内容不可依赖全局单例可变数据。

## 证据记录模板

后续建议存放 `docs/architecture/phase3/evidence/` 和 `phase4/evidence/`，本轮不创建假证据。每条记录：caseId、componentId、source/buildVersion、environment、steps、expected、actual、status（pass/fail/not-run）、截图/日志路径、未覆盖项。模拟、真实宿主、真实远端任务分开标注。第三阶段不得将第四阶段用例标为 pass。
