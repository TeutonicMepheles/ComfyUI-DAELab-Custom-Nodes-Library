## 决策

采用中性深色画布、媒体优先的卡片、卡片内参数与锚定浮层。生成参数无需依赖右侧 Inspector。首批强调色采用现有画布的淡紫色；表格旧绿色在迁移前保持现状，迁移后使用统一语义变量。

设计变量是视觉的唯一来源，共享组件源码是结构和行为的唯一来源。陈列和产品都引用同一组件；实例只持有各自的数据。新源码入口暂按 Vue 单文件组件规划，第三阶段验证构建兼容；现有纯 JS 模型与领域规则继续复用。
