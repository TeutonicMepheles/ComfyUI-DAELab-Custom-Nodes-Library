# 合并展厅与徽章 App Mode 的初次生成卡片

## 基线

- CNL 从当前安装源码的隔离快照 `eb7eacd6efb83a9187d6af8f80d88aa773616c58` 实施。该快照基于 `1481120281aaa95418c2609a1f9caca3a9f90c1f` 与安装目录当时的工作区内容。实施差异与快照分别保留。
- 验收使用用户目录两份 `20261119.4` 工作流的逐字节副本。展厅 SHA-256 为 `622c75f536332ccacfd1227c15a7ac806b90e10b4f3f2a57a09ee291ae05d28b`，徽章为 `9d788eae7867cd8e57a74b2693409f6f43f8661204499d3c7873d1d0337b20ae`。展厅用户文件与交付包同版本副本存在图结构差异。

## 界面与数据

- 初次生成保持原卡片的位置和各 App Mode 的样式。默认显示提示词框、模型选单、生成配置选单及生成操作。预计积分紧挨着生成按钮左侧，两者在窄侧栏里一起换行。张数、比例、尺寸、质量及徽章的「仅使用提示词」位于默认关闭的生成配置选单。展厅的模板、指定编辑区域和元素参考留在原功能区，局部修改、抠图和其他徽章阶段沿用原入口。
- 复用共享配置面板、字段和按钮。展厅的自有文本框绑定 `790.base_prompt`，原生字段留在宿主管理的 DOM 中，合并卡片挂载成功后临时隐藏该字段。徽章沿用 `daelabBadgePrototypeV1.buildPrompt`、`promptOnly` 及 `generation.build`。沿用原工作流节点、连线和序列化。
- 配置选单是临时界面状态，重新打开工作流时关闭。旧折叠键继续随工作流保留。展厅 `790` 停用时隐藏提示词区，`1040` 停用时隐藏模型参数和生成操作。徽章设计图停用时阻止图生图提交，提示词和配置选单内的「仅使用提示词」继续可用。临时停用与恢复不写旧折叠键。
- `loadModelAccess` 提供阶段有效模型、参数范围和默认模型。保留已保存的模型和参数，非法旧值由校验说明并等待修正，包括展厅旧张数 5–8。主动切换模型时保留兼容参数，用模型接入模块的有效默认值修正冲突。缺失模型时使用阶段默认值，已有但不可用的模型要求显式重选。徽章质量控件显示提交时的有效值，编辑写入原有的阶段质量字段。
- 展厅模板开启时沿用原组装，关闭时原样透传。徽章设计图模式允许空提示词，纯提示词模式要求非空白文本，继续使用原提交校验。

## 本批初次生成预计积分

- 展厅估算 `1040` 的本批输出。徽章估算当前 `8.8` 初次生成分支实际展开的一次批量图像调用。模型接入模块提供执行节点类型、提供方模型名及参数映射。
- 对宿主执行节点的 `price_badge` 按 `depends_on` 求值。输入使用实际提交的大小、质量、张数及参考端口数量。徽章参考数量按纯提示词、设计图、设计图加高度图分别为 0、1、2。公式处理张数；货币结果按 ComfyUI 积分换算。保持单值或区间，缺价或不可求值时显示「暂无法估算」。本地求值器随 CNL 打包。
- 输入变化时丢弃旧报价。面板销毁、切换阶段或重新加载后，旧回调无法更新新实例。估价状态独立于生成授权、校验及提交。

## 验收

- 在真实 ComfyUI 中分别从 CNL 独立和 CNL + Creative Canvas 安装打开两个验收副本。重跑 App Mode lint，覆盖卡片顺序和样式、宽窄侧栏、缩放、键盘焦点、折叠、Active／Bypass／Mute、App/节点图切换，以及保存重开。
- 检查同工作流 ID 的重新加载和两个工作流之间的状态隔离。验证阶段默认模型、已存模型失效、旧值保留、参数切换、提示词分支、单值及区间、张数计费、估价失败和过期回调。
- 拦截浏览器的生成 POST，比较基线与新界面的展厅 `1040.inputs` 和徽章请求。通过本地替身捕获徽章展开后的提示词、参考输入、模型参数及张数。测试宿主阻断外部 API。
