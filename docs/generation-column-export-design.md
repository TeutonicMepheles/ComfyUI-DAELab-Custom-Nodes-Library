# 生成列与剪辑成片导出

状态：设计建议，尚未实现。

## 用户行为

每个生成列顶部增加输出 Slot，连接到“导出”节点。来源用 node ID + field ID 标识，重命名和重排不改变连接身份。导出取连接列当前表格行顺序的已完成本地素材，按行序编号保存至同一目录或 ZIP；不按生成完成时间排序。输出清单保留 record ID、field ID 和原文件名，防止同名覆盖。

导出节点也接收剪辑节点的“剪辑成片”。只有剪辑成功导出的当前完整视频可用；编辑后的旧成片遵守既有失效约定。连接不会自动触发重新生成或重新渲染。

## 接口边界

现有 materialTargets 是一次素材快照接收入口，不能用作输出或伪造持久连线。需要先在 Creative Canvas API 增加兼容的列输出声明，复用 creative_canvas_view 与 creative_connections 的 Slot 投影、命中、连线、断线、撤销和生命周期。不得由表格自己复制端口手势。

表格业务适配器提供按 field ID 筛选的有序素材快照。导出业务节点放在业务库；画布核心只增加通用契约，不加入生成或导出依赖。真实图槽位和序列化索引保持兼容，定义列输出到原生数据输出的映射与来源选择信息，不能只画一个无执行语义的 Slot。

## 结果与缺失行为

默认要求所选列有结果且没有活动任务；生成中、结果过期、失败、文件丢失时说明对应行，不悄悄导出历史预览。可显式选择“仅导出已完成行”，导出前列出跳过行。导出基于不可变快照，点击后重排行不改变本次导出。隐藏列和删除列按稳定 ID 处理，删除来源不得自动换成相邻列。

## 验收

两表实例隔离；列重命名/重排/隐藏/删除；乱序任务完成仍按行排序；断线和撤销；工作流保存重载；混合图片视频集合、空集合和缺失本地文件；剪辑完整成片及编辑后的失效状态；50%/100%/150%缩放与窗口尺寸。导出操作不能产生付费生成。
