# 生成输入修复

业务节点库拥有此次修改；Creative Canvas 和 ComfyTV 上游不改动。

- 生成节点通过既有 table_exchange 接收多维表格及分镜解析器的 table_json，禁止将 storyboard_json 当成表格。
- @ 文本仍按同行稳定列 ID 展开，保留整列模板。复用原有提示词编辑、帧标签及图片选择菜单。
- 源表格没有生成结果列时，也保存首尾帧标签对应的图片绑定；回写、重新导入和多个生成实例同步不得丢失。
- 本地 H3 FL 菜单仅提供文生视频、首帧、首尾帧，不提供多图、视频或音频参考。旧的不支持模式保留数据并报错，不能作为可选项。

## 原因与修复

1. 生成节点只接受 DAELAB.Table，遗漏 DAELAB.ScriptParser；其 table_json 因而未导入。现统一使用表格来源判断，仍拒绝 storyboard_json。
2. 不含生成结果列的来源表格在回写时丢弃帧标签的图片绑定。现按标签 ID 保存并在导入时映射到任务；不依赖来源表格拥有生成结果列。
3. 帧图片菜单假设所有非单素材项都有 children，遇到文本列时报错。现仅提供图片，保留素材 ID 与单元格内序号。
4. 本地 FL 能力没有严格约束菜单，首帧与首尾帧也被合并。现展示三种独立模式，提交前拒绝不支持的旧模式；多图/视频参考接口不会被静默转换成首尾帧。
