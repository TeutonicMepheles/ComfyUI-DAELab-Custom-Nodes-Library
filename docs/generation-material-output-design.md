# 生成结果输出到画布素材节点

状态：修订后的实现方案，尚未实现。替代原“导出目录/ZIP/导出节点”方案。

## 行为与范围

每个生成列顶部提供结果输出 Slot。用户从 Slot 拖到画布空白处，松开后选择“输出为素材组”，在落点创建 DAELAB.MediaUpload 素材节点，并创建 DAELAB.MaterialGroup 将它们编组。列名作为组名；成员顺序严格使用操作时的表格 records 顺序，不使用任务完成时间、文件名或选中行顺序。表格仅有一条结果时也保持素材组语义。

剪辑的“剪辑成片”Slot 拖到空白处，选择“输出为视频素材”，创建一个素材节点，不增加导出业务节点。只接收与当前剪辑数据一致、成功渲染的完整成片，不拿单个片段或过期成片代替。

该操作是一次结果快照输出，不建立虚假的原生执行连线，也不添加动态原生输出槽位。源任务继续运行、源列重排或后续重新生成不会覆盖已经输出的素材节点。已有正常下游连线行为保持兼容。列输出到已存在输入节点的持续连接不在本次范围内。

## 可复用的现有实现

- Creative Canvas 的 creative_canvas_view.mjs 已拥有从输出 Slot 拖到空白处的新建入口；增加“输出为素材”的分支，并复用它的取消、位置换算、键盘入口和历史事务。
- material_group_model.mjs 的 collectionFor 按 properties.members 顺序读取素材；新组 members 必须按表格行顺序写入，后续连接剪辑可沿用 DAELAB_ASSETS。
- 使用现有 DAELAB.MediaUpload 和 DAELAB.MaterialGroup，不创建另一套展示节点或端口外观。
- video_edit.js 已通过 assets(node) 返回当前成片，ready:false 表示尚未成功渲染或结果已过期；保留此约束。

## 公开适配器契约

在 API v1 增加兼容的可选声明，例如 materialSources(node) -> [{element,key,label,clipElement}] 与 outputMaterials(node,key) -> 有序快照。名称为设计建议，实施时以契约评审确定。

表格适配器返回生成列顶部的来源元素和稳定 field ID，并在 outputMaterials 内读取自身表格状态。画布不读取 __dataTablePanel、行元数据或 LibTV 内部属性。剪辑复用已公开 assets(node)，不由输出入口读取剪辑私有实现。

现有 materialTargets 是接收快照入口，不能直接复用为输出。共享 Slot 层识别“素材快照来源”上下文，复用圆形接口、命中、微动和拖拽预览；松手形成素材实例而非原生持久连线。不使用 table_json 的字符串输出假装素材输出，不改变既有序列化槽位索引。

## 素材格式与本地文件

当前 media_upload_model.mjs 的 assetURL 固定使用 type=input；nodes/media_upload.py 也只允许 input 目录。因此不能把生成结果的 output 文件名直接塞进 asset_data。

新增通用本地素材导入能力：仅允许 Comfy 已配置目录内的图片/视频文件，校验类型与实际文件存在后，将 output 中的结果复制到 input/DAELAB 下的专用目录。此步骤只操作本地文件，不上传到 LibTV、不下载远端 URL、不触发生成。复制后创建兼容的 asset_data，保留原素材 ID、显示名及来源 node/field/record/request ID；重复输出可复用同内容的本地文件，但新节点具有独立图身份。

保持 DAELAB.MediaUpload、既有 asset_data 结构及 daelabCreativeCanvasV1 向后兼容。若将来决定扩展节点读取 output，需要单独审查预览、后端解析和素材组消费者，不能只改缩略图 URL。

## 顺序、部分完成与并发

用户开始拖动时锁定来源 node ID + field ID；提交输出时取不可变快照，包含 record ID、素材 ID、请求 ID、结果版本与行顺序。异步复制完成前检查来源是否删除或版本变化，发生变化则取消本次提交并说明原因，不换成相邻列或新的结果。

列有部分结果时，允许“输出已完成的 N 项”，明确提示跳过的行数，按剩余行在表中的相对顺序输出。不需要等待整列完成。未完成、失败、输入已变化的行即使保留历史预览也不加入快照；空集合和缺失文件阻止创建。重复点击同一次输出使用实例级忙碌保护；再次主动输出允许创建独立快照组。

复制校验全部成功后，素材节点与组在同一画布历史事务中创建。失败不得遗留半组节点；撤销一次移除本次所有新节点和组。文件复制使用稳定内容身份避免覆盖同名文件，撤销不删除可能被其他节点复用的文件。
