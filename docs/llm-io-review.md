# LLM 输入输出流程验证

> 历史阶段验收记录：下述 UI 来源选择、模拟输出及仅素材打组描述已被后续实现取代。当前输入输出、图文混合组、真实本地模型与验收边界以 [LLM Slot 输入输出](architecture/LLM_SLOT_IO.md) 为准。

本轮跳过所有模型调用，只生成带有「模拟结果」标记的文本。沿用 LLMStylePreviewB 稳定节点 ID、双栏面板和共享 table_controls（代理 creative_button）、creative_field、creative_panel_state。原 DeepSeek 传输与单条逻辑文件保留。

输入：直接文字（空行分段）、本地上传图片、画布上传素材／素材组／文本节点、一个图片列和一个文本列的多维表格。来源选择按加入顺序；真实输入连接按槽位顺序；同一来源 ID 去重。图片各自独立处理；图片和文字按序号配对，不广播、不压缩缺失行。表格与散装输入不可混用，提示先整理成表格。缺失素材及视频拒绝处理。

模式：文字支持润色/自定义；图片支持反推/自定义；图文支持全部。不完整配对只允许所有有效行均满足条件的模式；自定义可处理缺图或缺文字的行。空表、空输入不可运行。

输出：点击「生成」形成可审阅建议，再点击「输出多维表格」创建独立的 DAELAB.Table，图片列保留素材，文本列为模拟结果；记录 metadata 保留原文、原序号及模拟状态。原始输入不修改；输入变化使旧结果不可输出。结果和引用随工作流保存；不建立虚假持久输出连线，不支持 Comfy 队列执行模型。

兼容边界：当前画布打组只接收上传素材；本轮没有扩展为文本/嵌套组。多文本通过文本节点或空行分段输入。真实模型恢复、真实图像理解、队列执行不在本轮验收内。

验证用例位于本地 user/default/workflows/LLM-IO-20261015。每个案例必须在实际 ComfyUI 点击生成并输出，不将预填模拟表当作执行证据。

## 本轮验收证据

- 实际服务：8000 原联合安装；8211 仅画布＋业务库；8212 仅业务库，CPU 验收服务未提交模型任务。
- 8 类用例实际生成、输出并保存：文字 1/3 行，单图 1 行，多图/组/图文/表格 2 行，数量不一致 2 行且仅第 1 行有图。保存的 JSON 已独立检查每行原序号、图片数量、两列结构及 mock 提供者标记。
- 双实例独立、上游/本地输入变化后旧结果不可输出、保存刷新、图形/创作画布往返、Bypass 隐藏/Active 恢复、键盘焦点；45%–109% 等实际缩放范围和桌面视口检查。两实例正文 scrollWidth/clientWidth、scrollHeight/clientHeight 相等，无多余容器滚动。
- 仅业务库安装：两个实例正常加载，文本和两张本地图片上传后均可生成并输出真实表格。
- 35 项相关 Node 自动测试通过；不代替上述界面检查。未调用 DeepSeek、Qwen 或 GPT。
- 本地截图与可复现工作流：`user/llm-io-review/LLM输入输出-截图与工作流.zip`。测试图片是本地编号色块，仅检验顺序与引用，不检验模型图像理解。
