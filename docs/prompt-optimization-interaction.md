# 提示词优化交互补齐（2026-10-09）

用户要求先完成交互流程，再开始付费验收。本增量只修改业务面板、控制器状态投影及缓存版本；复用现有 text-side 侧栏、table_controls 按钮、Creative Canvas 适配器及主题，不修改共享画布或 ComfyTV。没有增加付费调用。

## 状态与动作

| 阶段 | 固定状态区 | 下一步 |
| --- | --- | --- |
| 缺少密钥或密钥草稿未保存 | 请先保存密钥 / 密钥尚未保存 | 保存到本页会话 |
| 输入法候选词未确认 | 正在输入 | 确认候选词 |
| 修改要求、尚未估算或估算过期 | 请更新估算 / 估算已失效 | 更新估算，不调用模型 |
| 估算中、不可估算 | 正在更新估算 / 暂时无法开始及原因 | 等待或处理原因 |
| 就绪 | 可以开始优化 | 用户点击开始才付费 |
| 创建批次、准备许可 | 正在创建任务 / 正在准备请求 | 不重复提交 |
| 等待模型 | 正在请求模型；当前行、等待秒数、已结束/总行数 | 等待或停止剩余行 |
| 停止或刷新恢复后暂停 | 已停止剩余行 / 已暂停 | 核对继续费用，再确认继续 |
| 查询中断 | 状态查询中断 | 查询原任务，不重新提交 |
| 成功、有改动 | 优化完成，等待应用 | 查看结果、比较并手动应用 |
| 成功、无改动 | 处理完成，原提示词保持不变 | 查看结果 |
| 已应用 | 部分建议已应用 / 建议已应用 | 可用撤销恢复 |
| 失败、无效、过期、unknown | 处理结束，部分结果需处理 / 存在未知结果 | 查看逐行原因，unknown 新请求需明确确认 |

“已结束”包含失败、停止和未知，不代表成功数量；没有模型提供的百分比时不显示虚构百分比。等待计时属于本页本次请求观察，不冒充刷新前完整耗时。秒数不进入每秒播报的 ARIA live 文本。

任务建立后折叠设置，让结果靠前。单格终态自动展开一次；后续刷新状态保留用户手动折叠选择。“查看结果”固定可达，滚动到结果并展开；“查看设置”打开原设置。结果仍需用户主动应用。完成后不再显示“点击开始才提交”或无关的旧估算过期提示。

页面 key 草稿不持久化；新输入的 key 未保存时禁用开始并给出原因。未知请求后即使直接编辑要求并重新估算，也必须确认原请求可能已计费，提交携带对应原请求 ID。
