# 提示词设置栏模板

用途：在表格每个提示词单元格底部，以参考图的紧凑“图标＋文字”形式显示生成设置。正文和首尾帧引用标签位于上方。

## 固定结构

`生成类型 → 模型 → 参考模式 → 比例与分辨率 → 时间`

| 顺序 | 配置键 | 图标（Remix Icon） | 显示规则 | 点击行为 |
| --- | --- | --- | --- | --- |
| 1 | `kind` | `video-line`；图片用 `image-line` | `video` 显示“视频生成”，`image` 显示“图片生成”；使用次级文字色 | 在按钮旁弹出图片／视频选择面板 |
| 2 | `model` | `box-3-line` | 显示实际模型名称；未选时显示“选择模型” | 弹出实际模型列表，当前项打勾 |
| 3 | `mode` | `film-line` | 首尾帧（合并首帧入口）、文生视频、多图参考、混合参考、文生图或参考图；未选时显示“选择方式” | 面板标题为“参考模式”；展示对应生成类型的完整方式，未声明支持时保存后警告 |
| 4 | `size` | `aspect-ratio-line` | 读取 `settings.ratio` 和 `settings.resolution`，用 ` · ` 分隔；本地模型有宽高时显示实际 `宽×高`，没有比例则按宽高约分 | 在浮层中编辑模型提供的比例、分辨率、宽度或高度参数 |
| 5 | `duration` | `time-line` | 使用 `settings.duration`，如 `2s`；未设时显示“设置时长”；图片生成隐藏整个时间项，不占位 | 灰色轨道、白色竖条滑块，下方显示刻度，右侧秒数输入框同步；每格 0.5 秒，拖动后松手保存。默认显示 0–30 秒，输入更大值自动扩展范围；超出模型范围时提示 |

示例：`视频生成 · MiniMax H3 FL（本地） · 首尾帧 · 12:7 · 768×448 · 2s`。
示例只说明格式，不会把参考图的模型名称或数值写入实际配置。

## 使用规则

1. **绑定实际生成列。** 使用 `generation.promptFieldId` 找到提示词列；没有关联的生成列时不显示这栏。同一提示词列服务多个生成列时，共用原有的一套默认值和逐格配置，只显示一个设置入口和一栏；各生成列的任务与结果独立保存。
2. **每个单元格独立配置。** 没有单独设置的格子继承列默认值（默认配置面板打开时使用其当前草稿）。底栏修改后自动保存当前格的完整参数快照，无需点保存；后续列默认值变动不覆盖这个格子。“应用到整列”同时将当前格的提示词和关联生成配置应用到现有各行，每行保存独立参数副本，后续不受默认值调整影响；新增行仍继承列默认值。浮层不提供恢复默认入口。选项按需读取，继续复用原模型能力接口和参数控件。
3. **区分默认值与当前格。** 类型、模型、方式、尺寸和时长在单元格底栏中修改时作用于当前提示词格及所有引用该提示词列的生成列；点击提示词列表头的设置图标打开右侧“列默认配置”，只编辑列默认参数和提示词来源；行提示词及首尾帧引用直接在表格中编辑，不在默认配置面板重复显示；多个生成列引用同一提示词列时，共用原配置；修改作用于这些生成列。底栏和默认配置只提供一个“首尾帧”选项，内部保留单帧与双帧提交方式：删除尾帧后使用单帧，删除全部帧标签后使用文生视频；单帧状态再次选择“首尾帧”可补回尾帧标签。首尾帧标签按当前格模式显示，仍只引用同行图片，可点击选图，也可 Backspace/Delete 删除。
4. **显示真实值。** 不为新模型猜测参数、默认时长或分辨率。模型能力接口用于默认值和兼容性提示；底部模型菜单仅展示当前生成类型的模型：视频与图片分开。切换模型保留生成类型、现有方式及参数；生成类型仅通过类型入口切换。生成方式按图片／视频区分；尺寸只显示当前模型声明的宽高或比例、分辨率参数，不混入其他模型的参数和预设。适用尺寸支持自定义输入；视频时长在底栏及默认配置中使用 0.5 秒步进滑条，拖动只更新读数、松手提交；不兼容项保存后警告，不自动替换或阻止选择。预设候选值不代表模型支持，实际执行能力仍由模型决定。
5. **生成逐行取配置。** 每行优先使用单元格已保存配置，否则读取列默认值；同批可有不同模型、模式、尺寸和时长。只有使用默认值的行需要生成前应用默认面板草稿。恢复原任务沿用原快照；本地／云端校验也按各行实际模型处理。设置栏本身不触发生成。
6. **不进入提示词。** 设置栏在正文编辑器外，不能被当作文本输入、删除或解析；模型只接收原有正文、素材引用及结构化生成配置。
7. **保持紧凑。** 每栏固定一行，图标 12px，文字 11px、字重 400，图标与文字统一使用比正文稍淡的次级文字色，控件高度 28px；模型名等长文本省略，悬浮显示完整内容。提示词列遵循普通列宽限制，可左右拖动调整，不再强制 560px。视频五项、图片四项按内容自适应排列；宽度不足时各项文字收缩并显示省略号，模型名优先收缩。底栏可用宽度不超过 135px 时只保留当前类型适用的图标，悬浮仍可查看完整名称和数值，点击仍打开对应面板。
8. **不覆盖正文。** 栏放在单元格底部，并按栏数预留空间。正文、引用标签和单元格内编辑继续可用。
9. **保留交互状态。** 按钮支持键盘焦点、悬浮和禁用态。更新配置只更新变化的栏文字，不重建正文或素材；浮层覆盖其他内容，不挤开单元格；支持 Tab、Esc、点击外部关闭及滚动定位，关闭节点或锚点移除时清理浮层。

10. **每行可调整高度。** 在画布上拖动任意单元格下边缘调整该行，行号格底边也有手柄；高度保存在 `row.meta.height`，支持保存重载、复制行与撤销。内容高度始终是下限，新增内容会自动撑高，不产生表格内部纵向滚动。双击本行下边缘恢复自适应；聚焦行号格底边手柄后可用上下键微调、Home 恢复自适应，Esc 取消拖动。

## 复用入口

实现：`web/table_prompt_settings.mjs`。

- `PROMPT_SETTINGS_TEMPLATE`：唯一的顺序、图标和参数键定义。
- `promptSettingsItems(config)`：把实际配置转换为显示项。
- `createPromptSettingsBar(onActivate)`：复用表格共享按钮创建设置栏；回调接收 `kind / model / mode / size / duration` 及所点按钮，作为浮层锚点。
- `bar.update(config, generationColumnName)`：同步草稿或已保存配置；内容未变化时不修改 DOM。
- `promptSettingsStyle`：由表格生成功能一次挂载，样式只作用于这栏及所属提示词格。

```js
const bar = createPromptSettingsBar((key, anchor) => chooseSetting(fieldId, recordId, key, anchor));
container.append(bar.root);
bar.update(generationConfig, generationColumnName);
```

独立配置保存在 `row.meta.generationSettings[promptFieldId][generationFieldId]` 中，只保存参数；素材继续使用现有引用，不复制媒体文件。旧工作流和新增行缺少此字段时自动继承列默认值。保存／重载和表格撤销沿用现有数据通道，行复制保留独立配置。

新增模型应沿用现有生成配置及能力接口。若新模型使用不同尺寸参数键，先在模板中明确显示、编辑规则，再扩展对应读取逻辑；不要在每个单元格复制一套分支。图标使用本地 Remix Icon 文件及随附许可证。

上述初版仅作静态语法检查，未运行界面检查、功能测试或实际生成；后续变更的验证记录见下文。

多个生成列共用提示词时，由提示词列记录原配置所属生成列 ID，列调序不改变配置；原生成列删除或改绑时，将默认值、逐格配置及首尾帧绑定交给仍引用本提示词的生成列。新建生成列不自动打开右侧配置面板。

## 生成节点统一参数面板（2026-10-22）

生成节点使用 `createPromptSettingsBar(callback, {combined:true})`：底部保留模型入口，其余参数合并为一个摘要按钮，例如 `文生视频 · 16:9 · 720p · 5s · 音频关闭`。点击摘要在同一个浮层编辑生成方式、比例、分辨率或宽高、时长、音频；不再提供“自定义”“更多设置”或恢复默认入口；隐藏的既有参数保留原值。时长使用横向秒数选项，范围读取模型声明。表格提示词单元格默认仍使用上文的独立入口。

选项来自当前模型及当前模式的能力声明，不复制参考图的固定参数。首帧与首尾帧共享入口；打开面板不修改保存值，旧工作流已有的不兼容方式仍可见。切换模型沿用既有默认值与本地模型归一化逻辑。每次修改继续使用原来的行配置、历史事务、兼容性提示和保存通道。面板更新保留焦点与滚动位置。

已评估并复用 `createPromptSettingsBar`、`createSettingsPopover`、`createGenerationSetting`、`modelCapabilities` 和 `setRowGenerationConfig` 所在的既有提交事务；未新增序列化格式、生成提交路径或画布业务依赖。

模型按钮与选项前使用本地单色品牌 SVG：Seedance 使用 ByteDance 图标，MiniMax 云端与本地版本使用 MiniMax 图标，Qwen 使用 Qwen 图标，Lib Image 使用其服务平台 LibTV 图标。未知模型回退到原有盒子图标。资源来源、版本及许可记录在 `web/vendor/model-icons/README.md`，不依赖运行时外网加载。

验证：新增参数/图标回归测试及既有生成、本地 Qwen、历史和 App Mode 测试共 37 项通过；修改模块语法检查与 `git diff --check` 通过。在实际 ComfyUI `127.0.0.1:8001` 的组合安装中，工作流 `1022-生成参数面板与模型图标` 检查了两个生成节点独立配置、Seedance 模式/清晰度/时长/音频修改、本地 MiniMax 宽高面板、保存重载、图形/创作画布/应用模式切换、Esc/外部点击与键盘焦点、54%/60%/84% 缩放及 1280×720 视口浮层边界。未提交生成任务。

验证限制：图片类型切换被当前环境缺少 `CLIPLoaderGGUF` 的既有本地模型检查阻止，图片参数映射仅有自动测试证明，未完成图片节点界面验收；未另起独立安装环境或验证窄屏视口。本次未修改安装集成或公开适配器协议。

### 2026-10-22 简化配置交互

模型菜单及生成参数浮层移除重置按钮。统一面板仅保留生成方式、比例、清晰度（或本地宽高）、生成时长与生成音频，使用分段选项、比例示意和横向时长条；不展示重复的“生成参数”标题、自定义输入折叠或更多设置。复用原有按钮、浮层与配置提交事务，隐藏参数不删除，打开面板不重写旧值。

本轮验证：参数、生成配置与历史回归测试共 20 项通过，语法及差异检查通过。实际 ComfyUI 双实例检查确认模型菜单和参数面板均无重置入口、无 details 折叠内容；修改 A 的 9 秒/音频不影响 B，B 的 9.5 秒独立保存。图形/创作画布切换及保存重载后数值保持；60%/75% 缩放、1280×720 视口、时长横向滚动及 Tab/Esc 焦点检查通过。未运行生成任务。
