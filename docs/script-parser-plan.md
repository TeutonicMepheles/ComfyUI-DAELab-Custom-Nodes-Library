## 数据和解析契约

- 首版 DOCX 表格，一条有效原始行对应一条任务，不自动拆镜或合并。多表分别选择表头和字段映射，按文档顺序导入。
- 每个原始行有去向和理由：任务、标题/章节、表头、空白、待确认。用户可纠正。图片行、缺文字行经确认可入表/输出，保留待补充标记，生成单独预检。
- 保存完整原文、原始单元格定位、章节/上下文、合并锚点及跨度。共享文字通过来源引用表达，不能伪装成独立原文。归一编辑不覆盖原文。
- 文件素材身份与图片出现身份分开，同图不同位置不可去重。新导入的同行多图按顺序进入同一参考图单元格，复用共享控件的 72×72 方形缩略图及预览。已有工作流保留参考列和素材 ID，不强制合并旧列。归属不明、嵌套表、浮动图等明确列入待确认，不能静默遗漏。图片格式/准备失败明确报错。
- 不做纯段落自动拆镜、OCR、默认多模态看图。标准模板本地规则；异构表手工映射；可选 AI 仅返回来源行/单元格 ID 和归类，由本地组装原文。严格校验来源、遗漏、重复、行边界；失败保留草稿，可手工完成全部验收。
- AI 显式触发，兼容接口协议/模型/超时/取消明确；凭据只存服务端，不进入工作流、浏览器响应或日志。
- 使用版本化 fields/records/meta。记录、字段、资产、来源身份各自独立。来源键=文件内容 SHA256+表定位+原始行定位；改名不影响去重，内容变化为新版本并提示，不自动覆盖旧任务。
- 追加按稳定字段 ID/已确认语义映射合并，类型冲突或歧义阻止提交；保留原编辑、结果、资产 ID。重复来源默认跳过并报告。
- 每表 500 行/64 列，包括所有实际原文/来源/参考/提示词/结果字段；追加按原记录+去重后新增记录计算。结构检查、映射、准备和提交全链路检查，超限报错，不截断、不部分提交。沿用 20 MiB 文档/128 MiB 解压限制。

## 交互与事务

上传→选表/表头→归一→对照预览→确认追加/替换→任务表→单独生成。

草稿和已确认数据分离；取消/失败不改变表格。首版草稿临时，不随刷新恢复，界面说明。已确认数据、顺序、素材、问题和持久化状态必须保存重载一致。

图片全部准备且校验成功后原子提交。追加/替换各为一个历史操作；撤销恢复字段、记录、映射、来源、素材及结果；不提前清理历史仍使用的素材。排队/运行/暂停中/恢复期间禁止替换，撤销重做不能绕过。

解析/AI/素材/生成均有实例、请求、数据版本校验；期间编辑需重新校验或中止。上传新文档、取消、删除、复制、重载均隔离旧响应。生成不可变快照，按原记录/请求身份回填。每实例独立状态/DOM/订阅/取消，销毁释放。

内容呈现、可调宽、完整高度，画布内编辑，宿主拥有标题/Slot/缩放/模式。不得注册会裁减任务行的素材整列输入目标。新类型登记 DAELAB_NODE_TYPES 并测 Bypass/Mute/Active。业务库单独安装使用原生面板，联合安装测试借用/归还，不能依赖 Canvas 才可工作。

图片/视频提示词及结果列独立；旁白/字幕/参考图默认不参与提示词，由用户选择。图片结果供视频显式引用，视频单独触发。
