# 分镜剧本解析器

新增节点 `DAELAB.ScriptParser`。从创作画布双击菜单添加“分镜剧本解析器”，或在原生节点菜单 DAELab/Table 中添加。重启 ComfyUI 后加载后端，刷新浏览器加载界面。

上传 DOCX，逐表选择表头和字段归类，再点击“归一并对照”。每个原始行可设为任务、标题/章节、表头、空白或待确认。每个单元格可覆盖列映射。新导入的同行图片按原始出现位置排序并存入同一参考图单元格，复用共享的 72×72 方形缩略图与放大预览。旧工作流不强制合并已有参考列。表外/浮动图片需指定所属行或明确保留待补充，不能推测。所有原文字段和来源保留。

带修订的文档按最终视图读取：包含插入文字，排除删除文字和域指令；不提供修订历史审阅。合并单元格保留锚点引用，章节可沿用该锚点，物理行不因此合并。提供空白示例 `examples/table/Script Parser.json`，其中已声明 App Mode 的解析器面板输入。

勾选“已核对原文和待补充项”后确认追加或替换。追加跳过相同文档指纹和行定位；同名内容变更作为新版本。替换是一个历史操作，生成排队/运行/暂停中/恢复时禁止。未确认草稿不会进入节点输出，刷新后需重新上传。

任务表复用现有表格编辑器、生成列、提示词整列模板和同行 @列。默认提示词仅引用画面，旁白、字幕、图片均需主动加入。图片和视频单独生成。节点执行只返回已确认 `table_json` 与 schema version 4 的 `storyboard_json`，不会自动触发任何服务。

`table_json` 保留完整任务表及图片/视频列模板。`storyboard_json` 是旧分镜消费协议的投影：以画面原文字段作为分镜正文，保留参考顺序、来源和缺失标记；不把生成列模板状态冒充旧版“最终提示词已审阅”状态。生成列仍通过本节点独立按钮执行。旧消费节点自身的批量上限不随本节点扩大，超限须分批选择。

## 可选 AI 归类

没有配置时全部流程可手工完成。本轮验收不配置密钥、不调用外部 AI。

可在 ComfyUI user 目录的 `default/DAELAB/script-parser-ai.json` 配置兼容 Chat Completions 协议的服务。该文件属于服务端私人配置，不能放进工作流或版本库。字段：

| 字段 | 用途 |
| --- | --- |
| endpoint | 完整 HTTPS 请求地址；本机服务允许 HTTP，不允许 URL 内嵌凭据/查询参数 |
| model | 服务提供的模型 ID |
| api_key | 可选 Bearer 凭据，只供服务端读取 |
| timeout_seconds | 5–120 秒，默认 60 |

接口接受 `model/messages/temperature/response_format`，返回 `choices[0].message.content` 内的 JSON。只在点击“AI 归类（可选）”时发送选中表格的原文与来源 ID，不发送图片。返回必须逐行逐单元格只归类，不增删来源、不跨行、不改写。校验失败保留原草稿；用户继续手工映射。修改列映射会清除该列的逐单元格覆盖，便于手动纠正。

## 保存与素材

原始上传不改动。临时结构缓存在 ComfyUI temp 下 `DAELAB/script-parser`；可在不需要草稿后清理。已准备图片在 input 下 `DAELAB/script-parser`，按原始图像内容指纹命名；撤销、保存或引用仍可能使用，不自动删除。迁移时一并复制工作流和引用图片目录。`table_json` 保留原文来源及未分配项；兼容分镜投影不覆盖缺镜号标记。

执行计划与逐项验收门槛见 [script-parser-plan.md](script-parser-plan.md)。
