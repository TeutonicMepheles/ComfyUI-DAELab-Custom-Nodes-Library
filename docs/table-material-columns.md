# 多维表格素材列

双击菜单“多维表格”复用 DAELAB.Table 和真实表格编辑器，新建两行两列内容字段；可编辑内容单元格支持文字或多个图片、视频，旧单素材表格继续保留数据。生成结果列维持原有输出格式。

列头 Slot 或列头接收素材后，按组顺序向下逐格填充，行数不足时补行，尾部已有行及内容保留。行头按当前可见、可编辑素材列的顺序向右逐格填充，列数不足时新增内容列。拖到单元格时将整个素材快照追加到这一格；文字值转为素材列表，已有素材保留。空组不清空表格，缺失素材拒绝整次填充。所有变化沿用表格撤销，源组后续变化不会再次覆盖数据。

单元格内按顺序展示 72px 正方形真实缩略图，序号位于左上角，不展示文件名或媒体控件；视频定位首段画面。仅选中格子的素材绑定悬停展开检测，从缩略图位置缓动展开为独立覆盖预览，等媒体原始尺寸加载完成后按原比例展开，尺寸变化时更新预览，完整展示画面不裁切；鼠标进入展开区域保持预览，离开缩略图及展开区域后收回，不改变单元格宽高。视频展开后显示原生播放控件，可直接播放、暂停和拖动进度，收回时暂停并隐藏控件。悬停预览时 Ctrl + 滚轮沿用所属画布缩放，预览保持展开并跟随缩略图位置。点击展开素材显示单项选中框并获得键盘焦点，Backspace/Delete 只移除该素材。取消格子选择时解除悬停检测并关闭预览，隐藏或重绘时清理，尊重减少动态效果设置。聚焦素材后按 Delete 或 Backspace 单项移除，双击或 Enter 打开完整预览，保留批量添加图片。可从缩略图或展开预览拖动单个素材到同表其他可编辑素材格，移动后从原格移除并追加到目标格，保留目标已有素材，支持撤销；同格内拖到素材左半边插入其前，右半边插入其后，同格排序及跨格拖入时其他素材平滑让位并以虚线占位框标示插入位置，使用与剪辑和素材组相同的动效时长及缓动曲线；拖动期间只预览，松手才保存顺序，取消恢复。跨格目标临时预留一个素材位置，空格也显示占位，退出时撤销预览；拖到空白处放到末尾，拖到自身不改变顺序。排序不改变素材身份，序号随顺序更新，已有引用继续指向同一素材，支持撤销。目标为已有文字或提示词时沿用覆盖选择，取消不改动来源。只读结果格不参与移动。

提示词输入 `@` 后只列出当前行实际有素材的列，空格和纯文字列不出现在素材菜单中；素材项与引用标签按类型显示“图片1”或“视频1”，素材名直接跟在序号后显示，长引用标签可换行。先选择列：本行该列只有一个素材时直接引用该文件，多个素材时悬停展开序号与缩略图菜单；方向键左右进入或退出子菜单，上下选择，Enter 插入。单行引用保存 `assetId`，在同一行内按素材身份查找；调换顺序或移到同一行的其他列仍指向该素材，列名和序号随实际位置更新。移到其他行或删除后显示失效，不回退到原位置的新素材。整列模板仍按各行对应序号选择初始素材，移动前固定受影响行的素材绑定。旧单行序号引用在读取时绑定当前素材。行内编辑、展开编辑器及后端提示词解析共用此语义。

复用 createTableEditor 的事务和 SnapshotHistory、createCreativeButton、画布 Slot 样式、collectionFor 有序素材序列以及公共业务适配器。未添加伪原生连线；未修改 ComfyTV。

单元测试用例覆盖双实例初始值、单格限制、混合素材顺序、行 ID、其他列及多余行保留、补行、撤销、序列化和异常原子性。

## 内容优先展示（2026-09-28 后续调整）

创作画布中通用表格默认展示表名、列名与内容网格，隐藏分镜工作台的常驻工具栏、映射、视频操作与固定高度调节。内容自然撑高，超过上限由单个表格容器滚动。小倍率保留网格，不替换成记录数摘要。

选择表格、列、单元格或行时，只出现当前层级的浮动菜单。菜单以屏幕像素定位并限制于画布视口，使用共享按钮与主题；列支持左右插入、重命名、复制、清空、删除和目标设置。Shift 选择表内区域不改变整个画布节点的选择。

新建列为 content 类型：值是文字字符串或最多一个本地素材组成的数组。旧 material_columns 表格的 assets 字段在读取时升级为 content，保留字段、行与素材 ID；其他旧分镜字段不迁移。列 goal=image 仅保存目标标记，没有模型调用或生成入口。

文字双击原位编辑，Ctrl+Enter 保存、Escape 取消、失焦保存；编辑器内多行粘贴不拆成多行记录。图片和视频占据可用列宽，保持比例；文件名悬浮或选中时显示。直接拖动内容单元格复用原有移动/交换事务。复制到同一行的另一列会为副本分配独立素材 ID，避免保存后冲突。

复用 createTableEditor、SnapshotHistory、列分隔条、素材组填充和共享 createCreativeButton。table_content_view.mjs 仅负责内容展示与实例菜单，卸载清理监听器、浮动菜单和定时器。原生图形模式继续显示完整表格工具，创作画布菜单在退出后消失。
