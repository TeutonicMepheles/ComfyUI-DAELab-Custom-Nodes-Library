# 最终提示词与素材引用：实施与验收记录

日期：2026-09-27。范围为 DAELab 自有代码，ComfyTV 上游未作功能修改。沿用现有节点 ID 与输出名称。

## 已交付

- 通用表格和分镜表共享字段映射、解析、结构化编辑、重新解析比较、复核及 LibTV 批量生成入口。通用表格保留裸 `table_json` 输出。
- 首次有效解析在最后创建提示词列；成功结果、列、绑定及 reviewed 模式作为一次历史事务提交。手工结果默认跳过，失败/过期行不覆盖，全部无有效结果时不改表。
- 正文引用与参与生成的素材分开管理；素材身份稳定，追加导入保留已有行；悬浮/键盘预览、双向高亮、定位及失效引用提示可用。
- 请求修订标识独立于历史快照，阻止迟到响应及比较面板覆盖新编辑。保存重开保留结构化结果。
- 后端统一校验正文、引用及源内容哈希；仅结构化引用转成执行引用，按精确位置处理标签紧接中文/数字的情况。
- 同批次保存素材文件快照；恢复使用快照，原文件删除后仍可恢复原任务，快照损坏或丢失则阻止。提交报告携带原任务指纹，旧结果不覆盖当前编辑或较新任务；撤销不回滚任务进度。

## 复用与实现边界

复用了 `createTableEditor`、`SnapshotHistory`、字段映射对话框、素材组、`createWorkbench`、LibTV 现有面板、原任务锁/恢复机制及共享 App Mode bypass 逻辑。新增提示词编辑器只负责现有普通字段控件不具备的结构化文本、引用选择和联动预览；没有新增视频服务或 AI 改写。

新增核心文件为 `prompt_compiler.py`（纯函数）、`prompt_service.py`（本地文件检查）、`prompt_api.py`（只读接口）、`media_snapshot.py`、`table_prompt_model.mjs`、`table_prompt_editor.mjs`。结构化引用的精确位置作为派生数据进入运行时请求身份，正文和 references 仍只有单一持久化真值。

解析与复核不查询 LibTV。模型能力最终在生成前按既有全批次预检核验；解析成功不代表模型兼容性已通过。批量解析上限为 100 行，表格上限 500 行/64 列，请求上限 8 MB。

## 验证边界与使用

- 初始解析阶段没有付费生成；随后完成下述 4 例真实验收。列标记与分栏的后续回归不重复消耗积分。
- 中文输入覆盖浏览器 composition 事件，不等于系统输入法人工实机体验。
- 用户常用的 ComfyUI 进程需重启以注册新增接口，然后刷新前端。通用表格先在“设置 → 字段映射”选择正文/素材，并在列头标记要参与视频的图片列；设置视频方式后解析，避免后续首尾帧角色变化带来再次复核。
- 快照是用于恢复任务的私有缓存，当前不自动清理，以免删除仍需恢复的内容；不要在任务尚需恢复时手工移除。
