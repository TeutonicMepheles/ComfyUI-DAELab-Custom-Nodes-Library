# 最终提示词与素材引用：执行方案

状态：P0、P1、P2 已实现，并通过本地解析、模拟提交和实际浏览器验收（2026-09-27）。另已完成 4 个真实 LibTV 视频的提交、参考顺序、文件指纹及播放验收；列宽交互与列级视频参考标记随后通过专项回归。系统中文输入法实机组词尚需人工体验，目前验证的是浏览器 composition 事件。详见 [实施与验收记录](PROMPT_PARSE_ACCEPTANCE.md)。

计划修订：2026-09-27。已确认通用表格也需要字段映射、解析、编辑和生成完整闭环；批量解析按下述事务与竞争保护规则实施。

目标：用户在表格里先看清“一行会用什么文字、哪些素材生成视频”，确认或修改后，再交给现有 LibTV 转接节点执行。

## 1. 本期范围

- 新增“解析”按钮，处理选中行；首次解析在表格最后新增“最终提示词”列，以后复用该列。
- 支持直接编辑解析结果、单行重新解析、撤销和重做。
- 提示词里的素材显示为高亮 `@素材名`；悬浮或键盘聚焦时，对应缩略图高亮，并显示预览。
- 编辑后的结果必须是实际提交给 LibTV 的内容。
- 通用表格和分镜表均提供字段映射、解析、编辑、复核及“生成选中项”，使用同一套编辑器、编译器和现有 LibTV 批量节点；分镜提供默认字段映射和解析预设。

本期“解析”指按规则整理已有字段、绑定素材，不调用 AI 理解图片或改写剧本。旁白、对白、原文归档不自动混入提示词。不增加新的视频生成通道，不改动 ComfyTV 上游。

## 2. 用户操作流程

```text
导入文稿 / 编辑通用表格 → 确认字段映射与列头“标记参考”
        ↓
勾选需要处理的行 → 解析
        ↓
最终提示词：检查文字、悬浮 @ 查看素材
        ↓
直接编辑，或单行重新解析并比较
        ↓
检查通过 → 生成选中项 → 现有 LibTV 设置与执行
```

界面示意（示意数据，不是实际运行截图）：

```text
[解析] [生成选中项]                         已选 2 行
镜号 │ 画面描述       │ 参考素材      │ 最终提示词
01   │ 人物走入大厅   │ [人物] [大厅] │ 人物走入大厅。
     │                │  ↑ 高亮      │ 参考素材：@人物 @大厅
     │                │              │ [已编辑] [编辑] [重新解析]
                                         └ 悬浮：图片预览、名称、来源
```

字体沿用 Alibaba PuHuiTi 3；列内保持简短预览，完整编辑在展开面板中完成，避免长文本撑高所有行。

### 通用表格的生成配置

- “字段映射”允许绑定正文、可选备注、参考素材、最终提示词及可选的逐行生成秒数/方式；素材组继续复用现有字段及顺序。通用表格不依赖镜号、文稿来源等分镜专属字段，正文映射不完整时定位配置问题，不猜测列名。
- 共享生成配置以字段 ID 保存于表格元数据，普通表格不强制套用分镜字段结构。分镜适配器将已有映射转换为同一编译上下文；新增配置启用后作为生成映射的唯一真值，历史映射只做迁移或兼容投影，不双向独立修改。
- 复用既有字段映射对话框、表格历史、素材组和 LibTV 设置面板；通用表格不新增另一套批量提交逻辑。通用表格的“输出表格”保留，另提供“解析”和“生成选中项”。
- `DAELAB.Table` 保留 `table_json` 输出名称及裸表格 JSON 格式；现有批量节点扩展接收带生成配置的裸表格、分镜表格封装和历史 `shots`。前端连接、预检及结果回填按来源节点读取对应数据，不硬编码 `storyboard_data` 或分镜专属输出名。
- 新配置的通用表格通过最终提示词复核后生成；未配置的普通表格仍可正常编辑、输出，但生成入口提示先完成映射和解析。历史分镜的旧模式行为按第 8 节保留。

### 后续已实现的列级视频参考规则

图片列表的图钉 ICON 决定整列是否作为视频参考。新列默认关闭；旧工作流既有映射和素材组迁移为可见标记。只收集已标记列，主参考列优先，其余列按表格顺序；全部关闭不回退到自动收集。取消标记保留原素材；旧 Prompt 的相关引用失效后必须复核或重解析。详见 [表格交互与数据契约](TABLE.md)。

## 3. 任务一：统一解析规则

**解决问题：** 现在前后端分别处理任务，用户看到的文字不一定等于最终提交内容。

**默认规则：**

1. 读取绑定的“画面描述”，去除首尾空白，保留原有段落。
2. 有镜头备注时，追加一段“镜头要求：……”。
3. 收集参与生成的素材：参考素材字段在先，素材组按当前列顺序在后，组内按图片顺序排列。
4. 有素材时追加“参考素材：@素材A @素材B ……”；不猜测人物、场景等语义，不自动编造参考用途。
5. 首帧、首尾帧模式按现有模型规则校验；展示明确的首帧、尾帧角色，顺序变化必须重新确认。

原图归档字段不参与；旁白和对白不参与。生成时长、模式作为参数传递，不默认写进正文。必填素材组缺失、画面描述为空时返回行级错误，不伪造结果。

**参数与角色：** 逐行生成方式、秒数优先于已连接 LibTV 面板默认值；模型与其他参数来自该面板。解析请求携带本次有效配置及配置修订标识。尚未配置模型/方式时允许整理文字和普通参考素材，但明确显示“生成配置待确认”，不宣称首尾帧角色或模型校验已通过。生成前必须确定有效配置；角色从普通参考变为首帧/尾帧或前后角色变化时，必须展示并确认。

**实现：** 新建 DAELab 自有 Python 纯函数编译模块，供解析接口和批量生成共同调用。外层服务负责本地路径校验、文件可读性检查和内容哈希，向编译器传入规范化素材描述；编译器不访问文件、网络或 Comfy 运行时。解析接口只读输入、返回结果，不上传素材、不调用 LibTV、不生成视频。前端不再复制一套字符串拼接规则。

解析阶段只使用已取得的模型能力缓存进行校验，缓存缺失时返回“模型兼容性待检查”；实际提交前沿用现有模型能力获取和全批次预检。解析成功不等于模型预检成功，不能根据缺失的模型信息推断支持。

**验收：** 相同输入得到相同结果；镜头备注只出现一次；预览中的有效文本及素材顺序与提交内容一致。

## 4. 任务二：保存可编辑结果和稳定引用

**解决问题：** `@image_1` 只是位置，不能作为图片身份。调换图片后，引用不能换人。

“最终提示词”使用现有 `json` 字段保存结构化内容，字段增加 `presentation: "prompt"` 渲染提示。用户看到的是文字和引用标签，不是 JSON。普通 JSON 字段维持原行为，避免新增基础字段类型破坏旧的类型转换逻辑。

建议契约：

```json
{
  "version": 1,
  "segments": [
    {"type": "text", "text": "人物走入大厅。\n参考素材："},
    {"type": "ref", "refId": "ref-a"}
  ],
  "references": [
    {"refId": "ref-a", "assetId": "asset-a", "fieldId": "refs", "role": "reference", "included": true}
  ],
  "sourceFingerprint": "...",
  "editOrigin": "parsed",
  "compilerVersion": 1
}
```

- 此字段值是提示词唯一真值；普通文本、`@image_N` 和 LibTV 节点占位符均为派生输出，不保存成另一份可独立修改的真值。
- 表格元数据用字段 ID 绑定最终提示词列，改列名、换列不影响绑定；首次放在最后，以后尊重用户的列顺序。
- `assetId` 引用素材对象已有的 `id`，不再给同一素材另建独立身份；它标识当前行内的素材项，`refId` 标识解析结果中的引用。行内素材 ID 必须唯一，复制素材位置需分配新 ID；DOM 定位使用“记录 ID + 素材 ID”，不能全局只按素材 ID 查找。
- 导入和旧数据迁移只在缺 ID 时补 ID；后续归一化、保存和旧格式投影不能反复生成 ID。
- 先修复 `applyLegacy` 经 URL 重建已有参考素材的路径：追加文稿不得重建原有行的素材身份。兼容投影不能作为新模式的回写来源；不能按文件名或 URL 去重来恢复不同素材位置的身份。
- 行内拖动保留素材 ID；跨行移动使两行的解析状态过期；复制整行时建立新行的引用作用域并保留内部对应关系。
- 相同文件在不同素材位置允许出现多次，不自动去重：首尾帧可以使用同一张图。重复标签显示来源/序号以供区分。
- 素材改名只更新标签。替换图片内容、改变所属字段或参与顺序，则要求复核；缺失素材成为失效引用，不能按名字猜测补绑。

**验收：** 保存重开、改名、换行、同名图片、复制行后引用仍正确；缺失引用明确报错。

## 5. 任务三：解析入口与编辑交互

**批量解析：** 无选中行时禁用。默认跳过已手动编辑行，待复核的手工结果也不覆盖，改用单行比较流程。发起时固定本次选中记录集合；期间改变勾选不扩大处理范围。返回后逐行执行第 7 节的竞争检查，在当时的最新表格上一次性合并可应用结果，保留期间发生的无关修改。

- 成功写入的结果、首次创建最终提示词列、字段绑定和首次启用 `prompt_mode: "reviewed"` 组成同一个历史事务，使用现有 `editor.change` 入口提交；不能先创建列或切换模式、再等待请求完成。
- 部分失败时提交仍有效的成功行；失败、手工跳过和过期丢弃的行保持原值。完成提示分别统计成功写入、手工跳过、失败、过期丢弃，并能定位失败或需重试的记录。
- 全部失败、全部跳过或全部过期时不创建列、不切换模式、不增加空历史步骤。首次模式切换提示随实际成功写入出现，明确其他行需要先解析。
- 一次撤销同时恢复本次结果、列、绑定和模式；重做恢复已确认写入的数据，不重新请求解析。批量解析本身不提交视频任务。

**单行重新解析：** 行菜单和展开编辑面板提供入口。展示旧结果与新结果，用户选择替换或取消；不因为源字段变化而自动覆盖编辑内容。展示比较前及点击替换时均检查请求所对应的修订标识，比较期间有新修改则废弃旧比较结果，不直接替换。

**独立编辑：** 编辑正文保留引用标签；输入 `@` 打开本行可用生成素材列表，含缩略图、名称、来源。中文输入法组词期间不触发解析或重绘。保存、取消、撤销有明确入口；编辑中不通过整表重绘移动光标。

**素材是否送入模型：** 标签与素材清单分开管理。删除正文中的 `@` 只删除文字引用，不偷偷删除首帧或其他输入；编辑面板同时显示“参与生成的素材”。取消素材参与时，若正文仍引用它，提示先移除引用；必填组及首尾帧数量继续校验。首次解析默认包含当前所有有效生成素材。

普通复制导出可读文本；应用内结构化复制携带引用关系。外部粘贴的 `@名称` 先视为普通文字，必须用素材选择器绑定，不能靠同名匹配。粘贴到提示词单元格须走专用转换，不把纯文本冒充合法 JSON。

新模式仅允许 `ref` 段产生执行引用。普通文字中的 `@image_N`、`@video_N`、`@audio_N` 及 LibTV 节点占位符属于保留执行语法：保留编辑原文，但校验时定位并报错，要求改写文字或用素材选择器显式绑定，不偷偷绑定、删除或替换。其他普通 `@名称` 保持文字。旧模式继续遵循原有占位符契约。

**验收：** 批量解析不覆盖手工修改；单行取消不改变数据；重新解析和编辑可撤销；正文和参与素材清单均可审阅。

## 6. 任务四：@ 与缩略图联动预览

- 鼠标悬浮或键盘聚焦 @ 标签：高亮本行对应缩略图，同时显示图片、名称、来源字段及角色。
- 建议延迟约 200 毫秒打开，轻微延迟关闭，允许鼠标进入预览窗口；Escape 关闭。
- 不因悬浮强制滚动表格。素材在屏外时，预览仍可查看，并提供“定位素材”；点击后才滚动到对应素材。
- 反向悬浮缩略图时，也高亮正文中的相关标签，便于核对多次引用。
- 素材不存在时显示失效样式和原因，不显示错误的替代图片。
- 使用安全 DOM 文本和结构化标签，不渲染用户 HTML。
- 浮层挂在当前工作台/原生 dialog 所在层级，避免被滚动区域裁切；跟随窗口边界调整位置。收起工作台、删除节点、切换 App Mode 时清理浮层和监听器。

**验收：** 多图横向滚动、紧凑行高、展开工作台、卡片视图、App Mode 均不裁切；键盘能够查看和关闭预览；悬浮不会改变选中行或素材顺序。

## 7. 任务五：过期提示与安全复核

解析状态与视频任务状态分别显示，避免“已解析”被误认为“已生成”。

| 解析状态 | 含义 | 生成行为 |
|---|---|---|
| 未解析 | 尚无结果 | 已启用最终提示词模式时阻止该行 |
| 已解析 | 规则结果与源数据一致 | 校验通过后可生成 |
| 已编辑 | 用户修改过结果，源数据未变 | 使用编辑结果 |
| 待复核 | 源文字、素材内容/顺序或映射改变 | 保留结果，先复核 |
| 引用失效 | 图片删除、文件不可读或绑定失效 | 阻止并定位问题 |

后端对规范化的源文字、字段映射、素材身份/内容/顺序/角色生成指纹。行排序、显示列名、列宽、隐藏状态不使结果过期；改变素材组列顺序会改变输入顺序，需要复核。模型和时长修改只触发生成参数及角色兼容性检查，不强制改写正文。

源指纹用于判断解析依据是否过期；提交指纹用于任务身份与恢复，包含实际最终文本、参与素材的内容哈希和顺序、有效模型/模式/参数。二者分别定义，不用 URL 指纹替代内容哈希。前端通过修订标识立即标记待检查，后端在解析、复核及提交前校验素材；未完成文件核对不能显示为已验证可生成。排除素材的变化可以触发源复核，但不应单独改变有效提交指纹。

待复核提供两个操作：①重新解析并比较；②保留编辑正文，核对素材清单后确认更新绑定。第二种也不能忽略失效引用；新增素材明确列出，由用户决定加入或排除。顺序变化涉及首尾帧时展示前后角色。

前端为每次异步请求保存记录 ID、相关源/目标/配置的修订标识、请求序号及表格加载代次；这些标识绑定到请求闭包，不随撤销快照回退，也不依赖服务器回传。接口接收表格快照、记录 ID、有效配置和操作类型，返回逐行结果及后端源指纹。已有解析结果的旧源指纹只作基线，不能要求首次解析前由浏览器计算文件哈希。返回时仅应用仍属于当前代次、当前请求且相关修订未变的行。

即使源字段未变，仅编辑最终正文或参与素材清单，也必须使旧请求失效。撤销/重做、重新加载、替换导入、删除行或销毁节点应推进相应修订/代次；这些用于竞争保护的计数不随历史快照回退，防止“改回原值”后旧响应重新有效。单行比较确认也采用同一保护。迟到响应不得覆盖编辑，丢弃后提示重试。

## 8. 任务六：接通真实生成与旧工作流

**新模式：** 第一次解析结果通过竞争检查并成功写入时，在同一历史事务中启用表格元数据 `prompt_mode: "reviewed"`。生成选中行必须有有效最终提示词，未解析、空结果、待复核、失效引用均阻止；不回退到原画面描述。启用时明确提示“后续生成使用最终提示词，其他行需先解析”。

**旧模式：** 没启用新模式的历史分镜工作流继续使用现有拼接规则。两种模式经过同一编译入口的显式分支，不能靠某个单元格是否为空猜测；没有生成配置的通用表格不进入旧模式分支。

**字段操作：** 隐藏最终提示词列不影响执行；删除该列须说明会清除解析结果，删除后保持新模式并报缺失字段，重新解析可重建。绑定中的提示词列禁止直接转换为其他类型，需明确解除绑定并确认清除解析结果后操作；模式仍保留并阻止缺字段生成。删除、解除绑定及模式切换各自形成完整的可撤销事务。历史分镜恢复旧模式必须是明确操作，保留已有解析结果以便恢复，不静默回退；通用表格关闭生成配置后回到仅编辑/输出状态。导入追加产生未解析新行，替换遵循现有确认流程。

**执行链：** 结构化段落和有序素材清单 → 后端验证文本段及引用段 → 仅为合法引用段生成 `@image_N` 等占位符及其精确位置 → LibTV runtime 按位置转换为节点引用并执行。位置记录同时进入请求身份；新模式不依赖整段正则，避免标签后紧接中文或数字时误绑定，普通文本中跨文字段拼接的保留语法也要拒绝。新模式不再追加镜头备注，不使用过时的兼容 `shots` 覆盖表格数据。验收中的“一致”指正文完整保留、每个引用对应同一素材及角色；展示名称、执行占位符和远端节点 ID 的合法转换单独断言。

**任务安全：** 保留现有模型能力检查、全批次预检、串行提交、请求身份和恢复机制。开始准备批次时冻结文字、参数及有序素材清单，为素材建立 DAELab 自有的不可变文件快照，复制后校验哈希与已复核内容一致；不一致时在任何生成提交前中止并要求复核。上传和恢复只读取该快照，不继续读取可被替换的原路径。重复素材位置仍保留各自输入位置，可以共用同一不可变文件内容。快照保留到关联任务无需恢复后再清理；缺失快照时明确报错，不悄悄读取原文件替代。

批次报告携带提交时的任务指纹、快照标识、记录 ID 和请求 ID；结果回填使用报告中的身份，不能用回填时的当前表格重新计算“原任务”指纹。旧任务结果只更新其任务记录；当前行内容已变化时显示结果属于旧版本，不能覆盖最终提示词、当前编辑或较新任务的结果。编辑撤销/重做只恢复编辑数据，不撤销远端任务或回滚任务进度；现有全表快照历史需与独立任务状态合并。改变内容仍遵循现有“新建批次编号”规则。

## 10. 执行优先级与阶段交付

| 阶段 | 必须完成 | 交付与通过条件 |
|---|---|---|
| P0：数据与执行安全 | 稳定 ID、两类表格共享契约、编译器及接口、旧模式分支、保留语法、过期阻断、请求竞争保护、批量事务、任务快照及回填隔离 | 模拟 CLI 证明预览正文与实际提交引用一致；追加导入不换 ID；手动结果不被覆盖；过期或失效数据不能提交 |
| P1：用户可操作闭环 | 两类表格的字段映射、解析/生成入口、最后一列、编辑、比较重解析、@绑定、素材清单、复核、复制粘贴及保存重开 | 通用表格从手动建表、分镜表从导入分别完成一行闭环；批量跳过手动行；撤销/重做及重开恢复正确 |
| P2：可视化与综合验收 | 标签与缩略图双向高亮、悬浮预览、键盘、定位、多视图和完整兼容回归 | 用真实文稿及通用表格检查引用关系，下列验收全部通过，再考虑真实生成验收 |

顺序为 P0 → P1 → P2。数据安全项不能推迟到可视化完成之后；P0 的生成验证采用模拟转接，不代表付费生成验收。每阶段涉及 UI 的变更均回归 App Mode 的 Active/Bypass/Muted 切换与恢复，复用共享 bypass 实现，不等到 P2 才接入。开发工时需在首阶段确认编辑组件方案后估算，不以未经验证的天数承诺月底交付。

## 11. 验收清单

### 逻辑与接口

- 无素材、1 张、多张、不同数量参考图，正文与素材顺序正确。
- 必填组缺失、空文本、引用越界、未知版本、不可读文件明确失败。
- 修改最终正文后，捕获最终 CLI 创建节点的模拟提交参数，验证完整文本、引用节点、连接顺序，无重复镜头备注；纯文字保留执行语法明确报错，不能被自动绑定。
- 通用裸表格、分镜表格封装和历史 `shots` 各走正确分支；未配置生成的通用表格仍能正常输出，不能静默按分镜旧模式生成。
- 追加导入及反复兼容投影不改变已有素材 ID；同一行内的素材位置 ID 唯一，公共素材跨行复用不串引用。
- 重复文件、同名素材、首尾帧同图允许保留各自位置；不错误去重。
- 解析后调换图片、删图、替换文件、跨行移动、改映射，能准确进入待复核或失效状态。
- 解析中仅编辑最终正文、编辑素材清单、删除行、连续请求乱序、撤销/重做、重新加载或导入替换，迟到响应均不覆盖；比较面板打开后修改再点替换也要拒绝旧结果。
- 批量部分成功只合并有效行；全部失败/跳过/过期不创建列、不切换模式、不增加历史步骤；一次撤销/重做同时恢复列、绑定、模式及结果，不重发请求且保留期间无关修改。
- 未指定模型/方式时不冒充角色校验通过；继承面板设置、行内覆盖及后续模式变化均使用实际有效配置，首尾帧角色变化要求确认。
- 排队期间替换同一路径文件、上传前源文件改变、恢复时快照缺失，不能上传未复核内容或静默换用原路径。
- 模拟旧任务完成回填及新旧任务乱序，报告指纹保持提交时身份，当前提示词和新修改不丢失；撤销编辑不回滚远端任务进度。

### 实际浏览器

- 分别用 808AI、风四、长征十二号甲三份已有文稿验证；私有文稿不进入公开测试夹具。
- 从真实导入结果解析、编辑、悬浮、单行重解析、撤销、保存重开；保留操作后的截图与断言记录。
- 通用表格从空表添加正文/素材字段，完成映射、解析、编辑、连接现有 LibTV 面板及模拟生成回填；无需先转换成分镜表。
- 截图至少包含：最终提示词整表、@与素材同步高亮、悬浮预览、重解析前后比较、缺失引用报错。
- 多图滚动、舒适/紧凑行高、展开/收起、卡片视图、App Mode，以及中文输入法和键盘操作正常；Active/Bypass/Muted 切换正确收起和恢复，浮层及监听器无残留。
- 执行现有表格、分镜导入、任务状态、LibTV 批量测试及 App Mode 覆盖检查。

标准验收使用本地解析、模拟转接和真实 UI，不触发付费生成。真实 LibTV 视频验收另行明确模型、参考素材及次数后执行；只有视频返回并可播放，才能称为真实生成验收通过。

## 12. 完成定义

用户在通用表格或分镜表中都能完成字段映射、解析、编辑、复核和生成，能通过 @ 清楚找到实际参与生成的素材；拖动、追加导入、重开和批量操作不会改变引用含义或丢失编辑；后端执行与界面确认结果一致。所有改动仅位于 DAELab 自有仓库。
