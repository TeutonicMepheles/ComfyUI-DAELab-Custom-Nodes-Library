# GPT Image 2 材质提示词

`GPTImage2MaterialPrompt` 把材质选择转换为稳定、可检查的 GPT Image 2 编辑提示词。材质示意图统一使用正视圆角方形样片；除亚金、亚银保留金属固有色外，其余材质使用灰阶表现。示意图只作为本地预览，不会由本节点上传或传入图像生成接口。

## 输入

- `material_id`：材质目录中的选项。前端会在节点上方显示对应缩略图。
- `base_prompt`：可选的目标区域说明，默认留空。只有用户填写后，输出中才会出现“编辑目标”段；旧工作流自动保存的旧默认文案会迁移为空。
- `additional_details`：可选的本次编辑补充要求。

节点不提供颜色开关、颜色输入或取色器。旧工作流中的颜色值和开关会在加载时丢弃，其余三个输入会迁移到当前顺序。

## 输出

- `prompt`：包含材质语义、融合要求、保持项和禁止项的完整提示词；仅在 `base_prompt` 非空时包含“编辑目标”段。
- `material_semantics`：所选材质的确定性物理语义和参考图颜色锁定指令，不包含目标色、HEX 或 sRGB。颜色锁定覆盖综合色相、饱和度和基础明度，并禁止材质引起全局或分区曝光、Gamma、对比度、色调映射、白平衡以及明暗漂移。
- `preview_image`：输出材质示意图。亚金、亚银保留金属固有色，其余材质由后端转为灰阶；它可连接预览或 Image Reel，但不会自动连接到 GPT Image 2 的图像输入。

## 徽章区域材质 V1

`DAELabBadgeMaterialRegionV1` 是面向首次徽章渲染的区域材质配置节点：

- `images` 输入徽章平面图，`foreground_mask` 可选输入徽章有效前景；建议连接 `BadgeDesignCanvas.design_foreground_mask`。
- 每条列表规则选择平面图源颜色、匹配阈值和材质。源颜色只定位区域，不是输出目标色。
- 节点本身默认把未命中的前景区域设为透明清漆；具体工作流可以显式改为与第一阶段一致的默认材质。#8.4 使用烤漆，以免未选区域被二次改成透明漆。
- 普通材质保留平面图固有颜色；亚金和亚银允许呈现自身固有金色或银色。
- `material_semantics` 独立进入第二个 GPT Image 2 材质生成节点。在 `#8.4 - Badge Workflow` 中，Image 1 接收彩色烤漆基础成片，Image 2 接收原始平面色块图；材质阶段只在选定区域覆盖表面响应，不得重建宏观高度或破坏未选区域既有烤漆连续性。
- `material_assignment` 保存结构化区域配置；`diagnostic_preview`、`default_material_mask` 和 `validation_report` 用于检查命中、重叠与默认覆盖情况，不需要传给生成节点。

## 扩充材质目录

1. 将材质预览图片放入 `web/material_thumbs/`。
2. 在 `web/materials.json` 中新增稳定 ID，并配置 `label`、`thumbnail`、`semantic`、`application`、`avoid`。
3. 重启 ComfyUI。无需修改 Python 节点代码。

材质语义只描述基材、金属度、反射、粗糙度、纹理尺度与方向以及微观表面细节，不描述目标综合色调，也不包含颜色值。不要把材质示意物体的形状、背景或棚拍构图写入 `semantic`。Prompt 固定锁定 Image 1 的宏观浮雕几何和当前表面连续性，并从 Image 2 继承固有色、综合色相、饱和度、基础明度关系和颜色分区。材质仍可产生物理合理的局部高光、反射与明暗变化，但不得重新配色。

## GPT Image 2 提示词策略

完整提示词使用英文短标题分段，明确区分图像职责、只修改什么、必须保持什么以及禁止项。区域材质语义固定声明“材质只控制光学响应和材质尺度的微结构，不创造宏观浮雕高度”：同高度的不同材质保持共用的标称承载面且视觉边界清晰；同材质、同高度连通区的承载面不得自行生成缝隙、折面或凸棱。高度阶段建立的最高外轮廓、轮廓线、文字描边和金属分隔线必须完整保留，任何材质都不得将其压平、降低、膨胀、遮盖或打断。闪粉、水钻等材质明确需要的微结构可以存在，但必须限制在对应区域并贴合既有高度包络，不得变成新的徽章层级。

默认提示不会引用材质预览图，因为它只作为本地选择器预览；如果工作流另行接入材质参考图，应同步更新基础提示词，准确说明每张输入图的编号和用途。
