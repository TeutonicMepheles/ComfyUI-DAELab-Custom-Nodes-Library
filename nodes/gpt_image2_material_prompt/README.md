# GPT Image 2 材质提示词

`GPTImage2MaterialPrompt` 把材质缩略图和目标颜色选择转换为稳定、可检查的 GPT Image 2 编辑提示词。材质球只作为本地预览，不会由本节点上传或传入图像生成接口。

## 输入

- `material_id`：材质目录中的选项。前端会在节点上方显示对应缩略图。
- `material_color`：启用自选颜色时使用的目标基准色。默认跟随材质目录中的颜色，通过节点内与 Multi Color Mask 共用的取色器直接选择，不需要输入 HEX。
- `base_prompt`：可选的目标区域说明，默认留空。只有用户填写后，输出中才会出现“编辑目标”段；旧工作流自动保存的旧默认文案会迁移为空。
- `additional_details`：可选的本次编辑补充要求。
- `use_color`：是否启用自选颜色。关闭时取色器折叠，材质只提供物理表面特性，并严格继承 Image 1 参考图中目标区域原有的颜色和颜色分区。

## 输出

- `prompt`：包含材质语义、融合要求、保持项和禁止项的完整提示词；仅在 `base_prompt` 非空时包含“编辑目标”段。
- `material_semantics`：所选材质的确定性语义。启用颜色时包含目标 HEX/sRGB；关闭时改用去色材质语义和参考图颜色锁定指令。
- `preview_image`：启用颜色时按目标颜色着色；关闭时输出未套用自选色的原始材质图。它可连接预览或 Image Reel，但不会自动连接到 GPT Image 2 的图像输入。
- `selected_color`：启用颜色时输出规范化后的 `#RRGGBB`，`auto` 会解析为材质默认色；关闭时输出空字符串。

## 扩充材质目录

1. 将材质预览图片放入 `web/material_thumbs/`。
2. 在 `web/materials.json` 中新增稳定 ID，并配置 `label`、`thumbnail`、`semantic`、`application`、`avoid`，以及对应的 `semantic_without_color`、`application_without_color`、`avoid_without_color`。
3. 重启 ComfyUI。无需修改 Python 节点代码。

材质语义应描述基材、综合色调、金属度、反射、粗糙度、纹理尺度与方向以及微观表面细节。不要把材质球形状、背景或预览图的棚拍构图写入 `semantic`。

启用颜色时，颜色只定义中性照明下的固有色或材质色调。关闭颜色时不得回退使用 `semantic`、材质名称、缩略图或目录默认色，而是只使用三个 `*_without_color` 字段，并锁定 Image 1 参考图中已有的固有色、综合色相、饱和度、基础明度关系和颜色分区；材质仍可依据原有光照产生物理合理的局部高光、反射与明暗变化，但不得重新配色。

## GPT Image 2 提示词策略

完整提示词明确区分“只修改什么”和“必须保持什么”，并使用短标题分段。默认提示不会引用 Image 2，因为材质球只作为选择器预览；如果工作流另行接入材质参考图，应同步更新基础提示词，准确说明每张输入图的编号和用途。
