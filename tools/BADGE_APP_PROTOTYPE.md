# Badge App Mode 交互原型

## 局部编辑工作区（2026-09-08 首版）

主操作与折叠调整：应用局部修改按钮独立放在两个卡片之后，占满可用宽度。两个卡片通过标题按钮互斥展开，初始展开选区；折叠时仅保留标题。展开状态只影响展示，不切换选区/修改方式、不清空设置或选区确认。标题支持键盘与 `aria-expanded`；继续沿用原生 App Mode 输入和 Bypass 可用性判断。

两块式调整：图片区下仅保留两个连续卡片。第 1 块“编辑哪个区域”包含按颜色/Polygon Mask、对应选区控件、折叠的颜色辅助设置和“查看选区”；第 2 块“对该区域做什么更改”包含语义描述/预设材质 Prompt、对应控件和模拟应用。隐藏卡片内重复的节点标题，原生控件仍留在 App Mode 原父容器。查看选区不再依赖填写修改描述；修改描述或切换材质模式不会清掉已经查看的选区。模拟应用在按钮内部沿用既有两阶段确认。现有 Polygon 支持情况未扩展为涂抹工具。

局部修改页复用效果图生成页的图片工作区：顶部固定显示节点 146 的实际上传目标图，支持上传、图库、拖入、原图/遮罩叠加/黑白遮罩和高度拖动条。下方依次为编辑区域（按颜色/手绘选区）、选区配置、进阶选项、修改内容（语义修改/材质替换）、对应配置及预览/模拟应用操作。两组选项复用 Boolean Hierarchy 的互斥状态接口；原生 App Mode 输入保留在原父容器，分组标题按当前输入插入。

颜色选区复用 `previewPixels`、页面内取色器及原有多颜色遮罩面板，不引入新的像素匹配算法。修改选区配置后提示预览待更新；目标图替换、选区方式或修改内容变化后撤销应用确认。应用按钮复用原型模拟运行与快照确认流程，仍不生成图片。手绘分支首版保留原有 Polygon 编辑器，尚未迁入顶部画布；Color ID Map 收入进阶选项，仅演示开关状态，当前上传图仍为实际取色源。

复用 `isNodeAvailableInAppMode` 与既有 App Mode Bypass 显隐。未更改节点类型、输入序列、连线、工作流 JSON 或 ComfyTV。相关 32 项前端测试通过；浏览器已检查置顶图片区、两组选项切换、颜色预览及模拟应用。手绘画布完整操作与独立 Muted 状态的人工验收尚未完成。

入口：`user/default/workflows/#8.6-UI - Badge App Mode Prototype.json`。
工作区 `user/default/workflows` 下另有同名副本，可直接从 ComfyUI 工作流列表打开并进入应用模式。

这是从 revision 17 抽取的独立工作流，使用新的 workflow UUID，包含 28 个节点、13 条连线、15 个 App 输入。
原 `#8.6 - Badge Workflow.json` 两份文件及全部既有前后端实现均未改动。

## 保留的交互

- 控制面板、效果图建立、局部修改、棚拍效果优化四个分页。
- Boolean Hierarchy / Get / Group Bypass 的父子、互斥、依赖和分支显隐。
- 图片上传、顶部参考图、取色时展开、高度层级、基础材质和特殊材质区域编辑。
- 颜色选区与 Polygon 编辑器、语义与材质切换。
- 模拟预览 → 开启应用 → 模拟应用；参数变化会撤销原型确认。

## 模拟边界

- 只增加原型适配器和独立模型；适配器仅在 `extra.daelabBadgePrototypeV1.version === 1` 时生效。
- 原生运行按钮、快捷键以及区域重抽通过 `app.queuePrompt` 时，原型会截获为前端模拟，不提交生成任务。
- 其他工作流仍以原来的参数、上下文和返回值调用原 `queuePrompt`。
- 没有 GPT 执行、Color ID Map 生成、后端快照确认、图像合成或棚拍生成节点。
- Color ID Map 仅演示开关和依赖。需要查看相应素材时，上传准备好的参考图。
- 效果图建立页在浏览器内计算颜色遮罩及离散高度预览；局部修改的模拟运行仍不计算实际选区像素面积，也不验证图像生成质量。
- 模拟状态保存在浏览器内存；刷新后需要重新预览确认。输入按普通工作流机制保存。
- 官方 App Mode 需要输出配置才能显示输入面板，故保留一个仅连接上传素材的普通 PreviewImage。模拟运行不伪造执行结果。
- 原生运行入口可能显示 ComfyUI 自带的排队提示，实际调用由原型适配器截获。面板中的“模拟运行”直接显示模拟状态。

## 参考图与未来接口

效果图建立页使用同一个顶部画布，通过“平面图 / 高度层次图”切换独立图片源，支持文件选择、拖入上传和选择已上传图片。配置区初始折叠：平面图显示背景剔除与材质分区，高度图显示高度层级配置。功能展开与启用开关独立，长列表在下方滚动。

“浏览已上传图片”打开缩略图网格，支持文件名搜索，当前图片置顶并以绿色标记。点击图片立即应用到当前图片页签；关闭或按 Escape 取消，保留原图。缩略图延迟加载，失败时显示“预览不可用”。

上传栏仅保留左侧平面图/高度图页签，右侧显示当前文件名、上传图标和图库图标。制作路线从控制面板设置。文件名支持省略和完整路径悬浮提示。项目 UI 图标统一优先使用用户指定的 Remix Icon（https://remixicon.com/），本次两个 SVG 及许可随扩展本地提供。

顶部页签现命名为“材质建立 / 高度建立”。高度建立带独立 Toggle，写入原型 metadata `heightEnabled`；未设置时沿用此前开启高度的行为。关闭不清空图片及配置，模拟运行不要求高度图。开启后，下方在背景剔除、材质分区之后显示“高度分区”；分区选择会同步显示对应图片。缺少高度图时显示明确上传空状态及提示，遮罩预览不可用。此开关尚未对接原 #8.6 的后端执行分支。

背景剔除与材质分区采用胶囊页签：点击主体展开或收起配置，右侧内嵌开关独立启用或禁用。启用为绿色边框及淡绿底色，禁用为灰色；展开状态用主体底部短线表示。开关保留键盘操作和辅助技术名称，不再显示外置复选框及状态文字。

效果图建立阶段隐藏基础材质选择器，并将原型节点 55 的基础材质固定为烤漆；特殊材质分区的目标材质仍可编辑。选色列表的五版布局为独立设计对比，尚未替换现有列表。

原型目标材质控件展开当前区域内的横向缩略图列表；点击样片更新该区域并自动收起。当前选择为绿色边框及勾选标记，支持左右箭头浏览、键盘方向键选择，以及 Escape 或点击外部取消。一次仅展开一个区域。适配器仅挂载于独立原型的建立页，不修改共享材质控件实现。

区域编辑采用单行布局：区域颜色、阈值、目标材质、强度百分比。目标材质输入宽度 110px；颜色策略放入“⋯”，强度使用拉宽的滑杆和实时百分比，沿用原配置提交逻辑。工具栏隐藏重抽按钮、配置版本/摘要和未配置提示。窄面板自动换行以保留可操作宽度。材质缩略图仍在区域下方展开。

背景/镂空选色项同样采用单行：颜色选择器、短色号、阈值，反转提取 Toggle 靠最右侧。移除重复的“颜色 N”“蒙版”行标签与反转说明文字；Toggle 保留辅助技术名称、键盘操作和悬浮状态提示，沿用原反转配置事件。

点击颜色块打开浏览器原生颜色面板，可使用面板内的吸管或颜色/RGB 选择器。不再拦截为直接 EyeDropper 调用，也不显示独立取色按钮。列表头部蓝色“遮罩预览”按钮显式更新当前列表对应的预览；修改颜色、阈值等配置后显示“预览待更新”。显示方式包括原图、遮罩叠加、黑白遮罩或离散高度图，以及背景透明剔除。该预览用于交互验证，不等同于 #8.6 后端的配准、材质合成或生成结果。

预览状态和图片页签保存在当前面板内存，离开建立页后重置；图片、颜色列表通过正常工作流保存。背景开关写入独立原型 metadata，材质开关沿用共享 Boolean Hierarchy 接口。

### 高度分层交互原型
新增 badge_height_board.mjs / badge_height_board_model.mjs，仅在原型高度分区替换旧列表。2–6 个实体层，默认 6；独立镂空区。颜色卡片支持原生选色、阈值、拖动手柄换层及下拉换层；每层添加颜色，总计上限沿用 16。减少层数按最近归一化高度迁移，提供一步撤销。未分配区域默认最低实体层，可调整。高度图预览沿用 previewPixels 的最近 RGB 距离匹配，等距灰度合成。编辑状态保存于 extra.daelabBadgePrototypeV1.heightBoard，不写入原有执行节点配置；后端对接另行处理。复用原型图片上传与预览、共享 App Mode 可用状态判断，原六档 widget 无法表达可变层数，因此采用独立前端模型。

滚动修正：效果图建立改为右侧输入面板统一纵向滚动；分层面板和选色列表按内容高度展开，不再使用 flex:1 1 0 和内部滚动。恢复原参考图尺寸，拖动换层的边缘滚动同步作用于外层输入面板。

每层 Alpha：移除颜色卡片的层级下拉框，层标题右侧提供 Alpha 数字输入（0–255 高度灰度）；镂空保持 0。每层自定义值保存于 heightBoard.alphas，合成预览与未分配区域使用该值。层数调整按最近原层继承自定义值，可撤销。

层数和 Alpha 控件更新：统一 − / ＋ 控制实体层数（2–6），边界禁用；Alpha 改为右对齐带 10 个刻度的原生 range（10%–100%，镂空固定 0）。已有灰度按最近档量化，预览使用相同量化值。颜色保持单列缩进。

固定槽位整组拖动：层名及 Alpha 保持位置；颜色容器提供整组手柄，拖动浮层仅显示色块和数量，目标提示层名和 Alpha。跨层拖动按插入顺序轮换颜色组，镂空不参与整组排序。复用单项指针拖动处理。层头左侧 Alpha、右侧 Remix Icon 向上/下插入文字按钮及垃圾桶删除；顶/中层向下插入，底层向上插入，2–6 层边界禁用。插层保留原槽位值，新值取相邻高度中值量化；删除将颜色合并到较低邻层，最低层合并到上一层，可撤销。

拖动语义更新：整组拖动只交换源层和目标层的全部颜色，中间层不变，Alpha 固定；单项拖动仍加入目标层并保留原颜色。整组目标使用整层实线框，单项目标使用颜色列表虚线框，浮层和落点文案区分交换/加入。此规则替代此前的顺次轮换。

效果图生成入口更新：主页签改为效果图生成；取消顶部材质建立/高度建立页签。图片下方统一为背景/镂空剔除、材质分区、高度建立三个胶囊开关按钮。按选中功能决定图片来源，前两者使用 node 1，高度使用 node 2；禁用高度后仍保留入口。原型布局标题同步更新，原 #8.6 未改。

顶部参考区置顶：主步骤页签与图片工作区使用 sticky，配置列表继续纵向滚动；图片高度随视口收缩。三个功能说明统一采用 Tip 底色与左侧强调线。原型内选色改为页面内颜色面板，支持色相、色板、HEX 和参考图吸色，规避内嵌浏览器原生颜色弹窗不可用；支持应用/取消/Escape。界面重建后自动恢复原型挂载。已在浏览器验证三个区颜色值回写及滚动置顶，原 #8.6 文件哈希未改变。

参考区高度拖动条：在三个功能按钮下增加横向 separator，复用高度面板的 Pointer Capture 交互模式。图像高度通常 120–600 CSS px，上限根据右侧根容器高度减去步骤页签、工具栏与 120 px 配置空间计算；极小窗口最小可降至 80 px。方向键 10 px，Shift 30 px，Home/End 到边界，双击默认，Escape 取消拖动。高度保存到原型 extra.referenceImageHeight（daelabBadgePrototypeV1 内），随布局变化重新约束，不写节点尺寸。浏览器验证键盘上下限与默认恢复；自动化拖动未观察到高度变化，鼠标拖动仍需人工确认。

### 分阶段模型输出配置（2026-09-08）

效果图生成与局部修改页底部分别增加模型输出配置和全宽“生成”按钮。两页共用 badge_generation_panel.mjs，配置独立保存到 extra.daelabBadgePrototypeV1.generation.build / local。旧原型缺少配置时读取 1:1、1K、1024×1024 的默认值；首次编辑随正常工作流机制保存，无需重建或覆盖现有原型 JSON。

运行时读取本机 OpenAIGPTImageNodeV2 的 gpt-image-2 尺寸预设，归类为五种比例：1:1、2:3、3:2、16:9、9:16。1K 对应 1024×1024、1024×1536、1536×1024；2K 对应 2048×2048、2048×1152、1152×2048。没有对应预设的分辨率按钮禁用，切换比例时自动选用可用档位。自定义宽高支持比例锁定、16 像素步长及节点范围/比例/总像素校验；自定义不冒充某个预设档位。分辨率不会修改模型 low/medium/high quality 参数。

复用现有原型挂载与局部选区确认流程、工作流变更通知，以及共享 isNodeAvailableInAppMode。现有 GPTImage2Config 面板仅支持 size/background/quality 三个原生字段，无法表达独立阶段及自定义宽高，故新建一个供两阶段共用的面板与纯模型，不改变旧控件。未新增执行节点、未修改 ComfyTV、正式 #8.6 或两份原型 JSON。

run(graph, stage) 只刷新当前阶段必要输入，并使用独立的 stageSnapshot 与会话。局部生成继续在按钮内部执行预览确认与模拟应用两步；不会验证效果图建立/棚拍素材，不触发其他阶段或真实队列。切换参数、工作流身份变化或阶段输入变化会使旧确认失效。原生整图模拟入口保留原有行为。
