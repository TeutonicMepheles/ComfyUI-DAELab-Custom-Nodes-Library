# Badge 8.7 Layout Studio — 开发工具，禁止作为交付运行时打包

独立的 GrapesJS 本地编辑器，第一阶段覆盖当前 8.7 的“局部修改”页面结构。
不修改原工作流、节点、web 模块、执行器或注册入口；不导入 ComfyUI app/api，不调用任何生成接口。

## 启动

在本目录运行 `npm ci`，然后 `npm start`，打开 http://127.0.0.1:8177 。
也可双击 `Start-Editor.cmd`（需要已安装 Node.js）。已有服务运行时直接打开网址即可。
可用环境变量 `BADGE_EDITOR_PORT` 调整端口。安装后运行不依赖 CDN。

## 当前可用

- 页面图层、区块和控件排序，宽高、间距、分栏、字体、颜色等属性；文本可在画布或右侧属性栏编辑。
- 读取实际 `#8.7 - Badge Workflow.json` 中局部修改的 inputKey，以及 `content/badge87/ui.zh-CN.json` 的文案。
- 复杂控件以明确标注的整体占位显示；不是现有 App Mode 的像素级复刻，条件分支同时展示供布局设计。
- 撤销/重做、三档视口、本浏览器草稿、工程 JSON 下载/导入、沙箱静态预览。
- 导出 presentation JSON，含内嵌 `previewHtml`；导出不含 GrapesJS、原工作流值、图片或执行代码。
- “下载 HTML”可直接导出单文件静态预览，双击即可查看。
- 导入检查版本、源工作流/文案摘要、组件身份、完整性和绑定；不接受脚本或外部 CSS 资源。

## 边界

这是可编辑、可保存和导出的布局原型，不是已经与执行器连接的新前端。
导出的 `previewOnly: true` 资源不会被现有 8.7 自动读取，不要替换 App Mode 文件。
真实运行适配、复杂组件内部属性及动态状态文案、完整视觉一致性留待后续接入。
目前改“提示词输入区域”只改占位展示，不改原工作流提示词。
工程 JSON 是编辑源，导出的资源由工程生成，不维护双向代码回写。
浏览器草稿不是长期备份，重要方案请下载工程。源快照改变时导入会拒绝旧工程，保留文件后另做迁移。

## 隔离与交付

整个 tools/badge87-layout-editor 目录（包括 node_modules、工程和文档）仅供开发，不应包含在客户交付包中。
后续交付流程应采用白名单收集运行资源；不能仅隐藏编辑按钮。
本工具没有生产打包命令，也没有写入原工程的服务端 API。所有编辑操作只影响浏览器草稿和下载文件。

## 复用与验证
